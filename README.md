<div align="center">"01  /  SYSTEM INITIALIZATION"

WELCOME TO THE LAST UPLOAD

</div>The year is uncertain. The world has changed.

Human memories are no longer confined to the mind. Technology has opened the door to recording, transferring, and manipulating the experiences that make us who we are.

Inside a futuristic laboratory, a mysterious experiment challenges the boundary between human consciousness and digital existence.

TheLastUpload is a cyberpunk-inspired game project exploring memory, identity, and the consequences of technology capable of changing what it means to be human.

The experience combines a futuristic visual direction, cinematic storytelling, character-driven scenes, and a developing third-person gameplay experience.

<div align="center">"07  /  BOOT SEQUENCE"

INSTALLATION GUIDE

</div>Requirements

- Unity Hub.
- A Unity Editor version compatible with the project.
- Git.
- A computer capable of running the project.

1. Clone the repository

git clone <YOUR_GITHUB_REPOSITORY_URL>

2. Navigate to the project folder

cd TheLastUpload

3. Open the project in Unity

1. Launch Unity Hub.
2. Select Add Project from Disk.
3. Choose the cloned repository folder.
4. Open it using the project's compatible Unity Editor version.
5. Wait for the assets to import.

4. Launch the game

1. Open the relevant scene in the Unity Editor.
2. Check for missing assets and references.
3. Press Play to test the current build.
